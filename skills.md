# EPI Rental - Frontend Skills Overview

## Objective

This project demonstrates the design and implementation of a modern SaaS dashboard for a virtual machine rental platform, built entirely with frontend technologies.

---

## 🧠 Core Frontend Skills

### UI/UX Design

* SaaS dashboard design patterns (cards, panels, metrics)
* Responsive layout using Flexbox and CSS Grid
* Dark/Light theme implementation
* Clean visual hierarchy and spacing
* Micro-interactions (hover states, animations, transitions)

---

### JavaScript (Vanilla)

* DOM manipulation and dynamic rendering
* Event-driven architecture
* State management (in-memory + localStorage)
* Modular function design
* UI updates without page reload

---

### Data Simulation

* Simulated backend logic using JavaScript
* Real-time updates (CPU, RAM usage)
* Mock datasets (users, virtual machines)
* Async behavior simulation (setTimeout, fake API patterns)

---

## ⚙️ SaaS Application Features

### Dashboard Systems

* Metrics overview (CPU, storage, cost)
* Dynamic VM listing with actions
* Real-time status updates

---

### VM Lifecycle Management

* Start / Stop / Delete actions
* Provisioning simulation pipeline
* Status transitions (running, stopped, provisioning)

---

### Admin Panel

* Multi-user system simulation
* Role-based UI (Admin / Client)
* Revenue and usage visualization

---

### Subscription & Billing UI

* Plan selection interface
* Payment simulation
* Dynamic cost display

---

## 📊 Advanced UI Components

* Activity timeline (event tracking)
* Notification system (toast + panel)
* Command palette (keyboard navigation)
* Search and filtering system
* Modal-based UI interactions

---

## 🎨 Visualization & Feedback

* Animated charts (CPU / RAM usage)
* Live updating metrics
* Visual status indicators (color-coded states)
* Deployment pipeline visualization

---

## 🧩 Architecture & Structure

* Component-like structure using vanilla JS
* Separation of concerns (UI / logic / data)
* Reusable rendering functions
* Clean and maintainable code organization

---

## 🚀 Tools & Technologies

* HTML5
* CSS3 (modern layout, variables, animations)
* JavaScript (ES6+)
* Optional: Chart.js (for graphs)

---

## 🎯 Outcome

A fully interactive frontend that mimics real-world cloud platforms (AWS, Azure, Proxmox) without requiring a backend.

The project focuses on user experience, system simulation, and modern SaaS interface design.
